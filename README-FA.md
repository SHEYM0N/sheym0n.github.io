# SHEYMON — نسخه ۱۳

## انتشار (مهم)
کل سایت در **یک فایل مستقل** است: `index.html`. همه‌ی تصاویر، استایل و اسکریپت داخل همین فایل هستند، پس دیگر عکسی گم نمی‌شود.
فقط همین‌ها را در ریشه‌ی مخزن (یا هاست) آپلود کن:
`index.html`، `favicon.png`، `apple-touch-icon.png`، `og-image.jpg`، `robots.txt`
(پوشه‌ی `src` فقط برای ویرایش‌های بعدی است و برای انتشار لازم نیست.)
فایل‌های قدیمی نسخه‌های قبل (webp، svg، css، js) را از مخزن پاک کن تا تداخل نکنند.

## تغییرات
- طراحی بر پایه‌ی زبان طراحی جدید iOS (Liquid Glass): لبه‌های شیشه‌ای، نوار پایین شناور که هنگام اسکرول جمع می‌شود، نشانگر لغزان منو و انیمیشن‌های فنری.
- نمای برنامه‌ی پویا ترید به‌صورت زنده با فونت واقعی سایت ساخته شده (نه عکس).
- تصویر اصلی با پارالکس و حرکت عمقی با ماوس، کارت‌های پروژه با اثر شیب سه‌بعدی و انعکاس نور.
- سئو: عنوان و توضیحات فارسی و انگلیسی، داده‌ی ساختاریافته و robots.txt.
