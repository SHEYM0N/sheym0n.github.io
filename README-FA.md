# SHEYMON — نسخه ۱۲

سایت شخصی (رزومه‌ی تعاملی) با حال‌وهوای iOS / macOS، تم روشن و تاریک و انیمیشن‌های فنری.

## تغییرات این نسخه
- نام فارسی و انگلیسی هر پروژه (پویا ترید / POYA TRADE، استلار ونگارد / STELLAR VANGUARD، ترازینو / Tarazino).
- تصاویر پروژه‌ها از روی فایل‌های خودِ برنامه‌ها ساخته شد و پنجره‌ی هر پروژه شامل تصویر برنامه، توضیحات، امکانات، گالری تصاویر و مشخصات است.
- تصاویر بازی اسکرین‌شات واقعی از اجرای بازی (`game-1..6.webp`) هستند.
- تصاویر پویا ترید (`trade-1..3.webp`, `trade-cover.webp`) نمای بازسازی‌شده‌ی محیط برنامه‌اند (رنگ‌ها، متن‌ها و تصویر پس‌زمینه از خود فایل EXE). برای نتیجه‌ی نهایی می‌توانی اسکرین‌شات واقعی را با همین نام‌ها جایگزین کنی.
- ترازینو هنوز تصویر نمایشی دارد (`project-tarazino.svg`)؛ با دادن اسکرین‌شات‌ها، گالری آن هم ساخته می‌شود.
- روش ساخت برنامه‌ها (زبان‌ها و فریم‌ورک‌ها) هیچ‌جای سایت ذکر نشده است.
- متن‌ها به لحن رزومه بازنویسی شد؛ «درباره من» جای «درباره SHEYMON» را گرفت و نام شخصی فقط در همان بخش آمده.
- بخش «فناوری‌ها» به «مهارت‌ها» تبدیل شد (حوزه‌ها، نه ابزارها).

## فایل‌ها
`index.html`، `styles.css`، `script.js`، تصاویر `*.webp`، لوگوها (`monogram.png` برای تم تاریک و `monogram-dark.png` برای تم روشن)، آیکن‌ها و `og-image.jpg`.
محتوای پنجره‌ی پروژه‌ها (فارسی و انگلیسی) در `script.js` بخش `P` قرار دارد.
