# SHEYMON Portfolio v2

نسخه‌ی بازطراحی‌شده‌ی سایت SHEYMON: تم مشکی/نقره‌ای، نشان گوتیک S، انیمیشن‌های اسکرول، افکت نور، کارت‌های تعاملی و جزئیات پروژه‌ها.

## آپدیت سایت فعلی در GitHub Pages
1. این ZIP را استخراج کن.
2. داخل مخزن GitHub، `Add file → Upload files` را باز کن.
3. همه‌ی فایل‌های داخل این پوشه را انتخاب کن؛ لازم نیست پوشه‌ای بسازی. فایل‌ها همگی در ریشه مخزن قرار می‌گیرند.
4. فایل‌های `index.html`، `styles.css`، `script.js` و فایل‌های تصویری را در همان مسیر ریشه آپلود کن و `Commit changes` را بزن.
5. اگر GitHub درباره‌ی جایگزینی فایل‌های هم‌نام پرسید، جایگزینی را تأیید کن. اگر فایل هم‌نام را اجازه‌ی آپلود نداد، آن فایل را از مخزن باز کن و با گزینه‌ی Edit یا Upload نسخه‌ی جدید جایگزین کن.
6. آدرس فعلی سایت حفظ می‌شود؛ اگر فوراً تغییر را ندیدی چند دقیقه صبر کن و صفحه را با رفرش/پاک‌کردن کش باز کن.
